# Page-by-page redesign plan and review

Updated 9 October 2026. Every page has a content-specific plan. Shared burgundy tokens, typography and controls provide consistency; the photograph, card, comparison and process layouts follow the visitor task. The homepage story, static/mobile fallback and product rail are protected. Twenty-four pages use a compact topic explorer; portal, contact, guides and 404 retain task-specific layouts.

## Review criteria

Review covers useful hierarchy, deliberate composition, a clear next action, complete source content, working interaction, readable mobile layout and keyboard behavior. The design ambition is not an external award or a ranking guarantee. Source plans are maintained in `scripts/design-page-strategies.mjs`; runtime topic plans are in `site/assets/js/content-flow.js`.

## Targeted review and validation

All 28 desktop and 28 mobile records are present. Additional targeted results are saved in `outputs/interactive-redesign-20261009/motion-flow/interactions.json`.

Separate targeted browser checks passed for all three BenefitsCare plans and mobile selected-detail expansion, full reading mode and collapse, keyboard Home / End / Right focus and selection, the services commercial deep link, next-topic chip visibility and catalogue search / empty state / clear behavior. The four policy-year tabs, four business-risk tabs and all portal role feature controls were exercised. Contact quick choices, required-field validation, Premier-prefilled unsent draft preparation, checklist state across chapters, the visible Print control, portal disclosure and an FAQ disclosure also passed.

Final build and SEO validation passed. The integrity check retained 988 of 988 substantive content units, all 28 pages' search metadata, all main-content links and the protected homepage chunk. Two SEO-generation runs left all 28 HTML files byte-identical. Three generic table headers were intentionally removed during the question-card conversion; three schema ItemLists changed order only. Full results are recorded in [the implementation report](INTERACTIVE-REDESIGN.md) and the saved integrity/regeneration evidence.

Reduced-motion and print behavior were reviewed in code. This record does not claim OS/browser preference emulation, an actual print/export, a new cross-browser review, assistive-technology testing or a complete accessibility audit.

All substantive copy remains in the static HTML. JavaScript moves the original section nodes into the explorer, full reading mode reveals them together, and no-JavaScript pages remain continuously readable. Insurance qualifications and source links retain their meaning. Public deployment and external search outcomes are outside this local browser ledger.
